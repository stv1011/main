왜 익힘인가

배웠는데,
왜 실제 문장에서는 낯설까요?

01

공부한 내용과 실제 일본어가 따로 느껴진다

문법 설명은 이해했지만, 뉴스나 대화에서 만나면 의미를 바로 잡기 어렵습니다.

02

답을 보고 이해한 것과 직접 푸는 것은 다르다

해설을 읽을 때는 알겠는데, 새로운 문장에서는 다시 헷갈립니다.

03

헷갈린 표현을 다시 만날 기회가 부족하다

틀린 내용을 정리해도, 언제 무엇을 복습할지 직접 챙기기는 쉽지 않습니다.

익힘은 하나의 학습 항목을 중심으로
설명 · 문제 · 실제 문장 · 복습을 연결합니다.

연결은 뉴스의 핵심 항목부터 시작해 순차적으로 넓혀 가고 있습니다.

러닝루프

이해하고, 적용하고,
다시 만나며 익힙니다.

JLPT 문법은 개념과 문제를 중심으로, 뉴스 일본어는 짧은 기사와 표현을 중심으로 학습합니다. 시작하는 방식은 달라도, 배운 내용을 확인하고 다시 익히는 방향은 같습니다.

  1. 01

    이해

    학습지와 설명으로 문법을 배우고, 뉴스에서는 표현이 쓰이는 맥락을 살펴봅니다.

  2. 02

    적용

    답을 직접 선택하고 제출하며 이해한 내용을 확인합니다.

  3. 03

    확인

    채점과 해설을 보며 맞힌 이유와 헷갈린 지점을 점검합니다.

  4. 04

    복습

    틀렸거나 헷갈린 항목을 다시 풀고, 연결된 설명으로 돌아갑니다.

학습 항목별 해설 영상은 준비 중입니다. 공개되면 항목별로 안내하며, 지금 공개된 학습만으로도 이해–적용–확인–복습을 진행할 수 있습니다.

코스 연결 업데이트 예정

뉴스에서 만난 표현을,
기존 학습과 이어갑니다.

뉴스의 핵심 단어와 문법을 기존 단어 A~C, JLPT 문법 N3~N1의 같은 항목과 연결합니다. 알고 있는 표현은 실제 문장에서 확인하고, 헷갈리는 표현은 연결된 설명과 복습으로 보완하세요.

우선 뉴스의 핵심 항목부터 연결합니다. 기존 코스에 없는 표현은 뉴스 안의 설명으로 학습하며, 모든 단어와 문법이 연결되어 있는 것은 아닙니다. 단어 A~C와 JLPT N3~N1은 서로 다른 기준의 과정입니다.

채점과 학습 기록

끝냈다는 기록에,
어떻게 풀었는지를 더합니다.

답을 직접 제출하고 채점 결과와 해설을 확인합니다. 맞혔어도 헷갈린 항목은 표시해 다시 연습할 수 있습니다.

  • 첫 시도와 재시도 구분

    처음 풀었을 때와 다시 풀었을 때를 나눠 봅니다.

  • 정답을 먼저 확인한 경우 구분

    답을 보고 이해한 것과 직접 맞힌 것을 섞지 않습니다.

  • 오답 · 헷갈림 항목 복습

    표시해 둔 항목을 다시 꺼내 풀어봅니다.

  • 새로운 문장에서 다시 적용

    같은 문제가 아니라 다른 문장으로 확인합니다.

학습 완료와 표현 이해는 구분합니다. 한 문제를 맞혔다고 완전히 익혔다고 판단하지 않습니다.

자주 묻는 질문

궁금한 점을 모았습니다

지금 바로 사용할 수 있나요?

네. 무료 베타로 공개된 과정을 웹에서 체험할 수 있습니다. 과정별 공개 범위는 각 코스에서 안내합니다.

회원가입이나 앱 설치가 필요한가요?

현재 베타는 별도 계정 가입과 설치 없이 웹에서 이용합니다.

뉴스 일본어는 어떤 과정인가요?

짧은 학습용 뉴스 원고를 읽고 핵심 어휘 · 표현을 배운 뒤, 문제로 확인하는 과정입니다. 이번 업데이트에서는 기존 단어 · 문법과의 연결 및 다음 날 복습을 순차적으로 추가합니다.

뉴스의 멤버 심화는 유료인가요?

현재 베타에서는 결제 없이 체험할 수 있습니다. 정식 출시의 가격과 제공 범위는 확정 후 안내합니다.

뉴스에 나온 모든 단어가 기존 단어장과 연결되나요?

우선 기사별 핵심 항목부터 연결합니다. 기존 코스에 없는 표현은 뉴스 안의 설명과 문제로 학습합니다.

해설 영상도 볼 수 있나요?

해설 영상은 준비 중입니다. 공개되면 학습 항목별로 안내하며, 지금은 영상 없이도 각 과정의 학습을 진행할 수 있습니다.

다른 기기에서도 학습 기록이 이어지나요?

현재는 기기 · 브라우저에 저장되므로 자동으로 이어지지 않습니다. 정식 출시 단계에서 계정 기반 저장을 도입할 계획입니다.

학습 기록이 자동으로 운영자에게 전송되나요?

현재 베타에는 서버 자동 수집 기능이 없습니다. 베타 분석에 참여하는 경우, 별도 안내에 따라 내보낸 기록 파일을 제출하는 방식입니다.

의견을 보낼 수 있나요?

네. 실제로 사용하며 느낀 불편과 개선 의견을 기다리고 있습니다. 의견을 받는 창구는 준비되는 대로 이 페이지에서 안내합니다.
