# 익힘 랜딩 페이지

일본어 학습 플랫폼 **익힘**(일본어 러닝루프 with 쇼타쌤)의 서비스 소개 · 유입 페이지입니다.
빌드 도구 없이 동작하는 정적 사이트(HTML · CSS · JS)로, 그대로 올리면 바로 배포됩니다.

## 구성

```
landing/
├── index.html      # 페이지 전체 (섹션별 주석 표시)
├── styles.css      # 브랜드 토큰 + 레이아웃 + 반응형
├── main.js         # 헤더 상태, 모바일 메뉴, 스크롤 등장, FAQ 아코디언
└── assets/
    ├── logo.png, logo-192.png, favicon.png   # 브랜드 로고
    ├── shota.jpg / .webp / shota-sm.jpg      # 쇼타쌤 프로필 (흑백)
    └── og.jpg                                # 공유용 썸네일 (1200×630)
```

## 섹션 순서

1. **히어로** — “보는 공부에서, 내 것이 되는 공부로.” + 무료 체험 CTA
2. **문제 제기** — 자료는 많지만 연결되지 않는다 (3가지)
3. **일본어 러닝루프** — 학습지 → 영상 → 문제풀이 → 오답복습 (다이어그램 + 4단계)
4. **차별점** — 전문가 설계 / 끊기지 않는 구조 / 작동하는 프로토타입
5. **쇼타쌤** — 집필 · 방송 · 연구 이력
6. **추천 대상** — 체크리스트 6가지
7. **커리큘럼과 로드맵** — 제공 중 / 제작 중 / 예정 구분 표기
8. **이용권** — 무료 체험(현재 이용 가능) + N2 · N3 90일 이용권(출시 예정)
9. **FAQ** — 6문항 (검색용 FAQ 구조화 데이터 포함)
10. **마지막 CTA + 푸터**

## 로컬에서 보기

```bash
cd landing
python3 -m http.server 8080   # http://localhost:8080
```

## 배포

- **Vercel** — 이 저장소를 연결하고 *Root Directory* 를 `landing` 으로 지정하면 됩니다. (빌드 명령 없음 / 정적)
- **GitHub Pages, Netlify, S3** 등 — `landing/` 폴더를 그대로 업로드하면 동작합니다.

## 배포 전에 채워야 할 항목

| 위치 | 내용 |
| --- | --- |
| `index.html` 푸터 | 문의 이메일이 `hello@example.com` 자리표시자입니다. 실제 주소로 교체 |
| `index.html` 푸터 | 인스타그램 · 유튜브 채널 링크 추가 (초기 고객 유입 경로) |
| `index.html` `<head>` | 도메인 확정 후 `og:image` 절대 URL과 `canonical` 추가 |
| 이용권 섹션 | 가격 · 제공 범위는 검증용 가설이므로 확정 후 수정 |
| 커리큘럼 섹션 | 해설 영상 촬영 완료 시 `제작 중` → `제공 중` 으로 변경 |

## 표기 원칙

현재 준비된 것(N2 · N3 문법 학습지 · 문제풀이 · 오답복습)과 준비 중인 것(해설 영상, 어휘 · 청해, 상위 · 하위 급수)을
페이지 안에서 명확히 구분해 표기했습니다. 아직 구현되지 않은 개인화 · AI 기능은 문구에 포함하지 않았습니다.
