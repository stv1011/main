# 책 표지 이미지

아래 파일명 그대로 저장하면 해당 카드의 표지가 자동으로 바뀝니다.
파일이 없으면 브랜드 색상의 자리표시 표지가 대신 보입니다. (코드 수정 불필요)

| 파일명 | 책 |
| --- | --- |
| `jlpt-n3.jpg` | 이번에 제대로 합격 JLPT N3 |
| `shorts-nihongo.jpg` | 80개 쇼츠로 배우는 쇼츠 일본어 초급회화 |
| `jlpt-mock.jpg` | 이번에 제대로 합격 JLPT 실전모의고사 시리즈 |

| `eju.jpg` | EJU 실전 모의고사 종합과목 |

- 권장 규격: 세로형, 가로 600px 내외, 비율 3 : 4.15 (카드가 `object-fit: cover`로 잘라 맞춥니다)
- 형식: JPG 권장. PNG·WebP를 쓰려면 `teacher.html`의 `src` 확장자도 함께 바꿔주세요.
- 출판사 제공 이미지나 직접 촬영한 사진을 사용하세요.
