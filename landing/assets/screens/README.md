# 앱 화면 목업 이미지

랜딩 페이지의 휴대전화 목업에 들어가는 실제 앱 화면입니다.
파일이 없으면 화면 이름과 "실제 화면 준비 중" 안내가 대신 보입니다. (코드 수정 불필요)

## 규격과 처리

- 휴대전화 스크린샷을 그대로 보내면 됩니다. **상단 상태표시줄 · 주소창과 하단 내비게이션 바는 잘라서** 넣습니다.
- 목업 화면 비율은 잘라낸 스크린샷 비율(600 × 1119)에 맞춰 두었습니다. 다른 기기로 찍으면 비율을 다시 맞춥니다.
- 가로 600px로 줄여 JPG로 저장합니다. 개인정보나 테스트 계정 정보가 보이지 않는지 확인하세요.
- 아직 공개되지 않은 기능의 화면은 사용하지 않습니다.
