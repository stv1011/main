# 앱 화면 목업 이미지

`travel.html`(익힘 외국어 — 여행회화)의 휴대전화 목업에 들어가는 실제 앱 화면입니다.
아래 파일명 그대로 저장하면 목업에 자동으로 들어갑니다.
파일이 없으면 화면 이름과 "실제 화면 준비 중" 안내가 대신 보입니다. (코드 수정 불필요)

| 파일명 | 들어가는 위치 | 필요한 화면 |
| --- | --- | --- |
| `hero-learn.png` | 첫 화면 · 앞쪽 | 대표 표현 학습 화면 |
| `hero-language.png` | 첫 화면 · 뒤쪽 | 언어 선택 화면 |
| `flow-language.png` | 학습 방식 01 | 언어 선택 화면 |
| `flow-situations.png` | 학습 방식 02 | 상황 · 회차 목록 화면 |
| `flow-expression.png` | 학습 방식 03 | 표현 학습 화면 |
| `situation-example.png` | 여행 상황 | 실제 제공 중인 상황의 학습 화면 |
| `korean-course.png` | 한국어 과정 | 안내 언어가 적용된 한국어 학습 화면 |

## 규격

- 세로형 스크린샷, 가로 **600px 내외** 권장 (비율 9 : 18.5로 잘라 맞춥니다)
- 화면의 중요한 글자가 읽히도록, 축소 상태에서 확인한 뒤 사용하세요
- 서로 다른 언어의 화면을 섞어 배치하면 다국어 서비스임이 드러납니다
- 아직 없는 기능의 화면은 넣지 않습니다

## 주의

목업 주변 설명과 실제 화면의 언어·기능이 일치해야 합니다.
화면을 교체한 뒤에는 `travel.html`의 `alt` 텍스트와 `data-screen` 이름도 함께 맞춰주세요.
